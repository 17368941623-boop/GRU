# 0903：lookback=65 模型训练包

## 固定实验条件

- 预测对象：未来第 15 步的 `Delta Thv`，评价时恢复为绝对温度。
- 历史窗口：65 步。
- 公共预测起点：120 步，确保不同模型使用完全相同的窗口和标签。
- 未来输入：仅使用阀门命令 `u(t)` 至 `u(t+14)`。
- 温度、压力、流量等测量量只使用到当前时刻，不使用未来测量值。
- StandardScaler 仅使用 `train_clean.pkl` 拟合。
- 模型权重和早停仅依据 Original 260501 验证集。
- 两套脚本均不读取测试集，也不会生成测试指标。

## 一、四种图模型，每种 10 seeds

包括：

1. Parallel GRU–MLP–GNN
2. Parallel GRU–KAN–GNN
3. Serial MLP–GNN–GRU
4. Serial KAN–GNN–GRU

使用种子：`42, 52, 62, 72, 82, 92, 102, 112, 122, 132`。

激活服务器上的 Conda 环境后，在 `0903` 目录执行：

```bash
bash run_graph_models_10seeds.sh
```

脚本默认启动 5 个互不重复的训练 worker。不要再手工启动第二份相同脚本。结果保存到：

```text
outputs_graph_10seeds/
```

## 二、TCN，单独 5 seeds

使用种子：`42, 62, 82, 102, 122`。

另开一个终端，在 `0903` 目录执行：

```bash
bash run_tcn_5seeds.sh
```

TCN 顺序训练五个种子，结果独立保存到：

```text
outputs_tcn_5seeds/
```

图模型脚本和 TCN 脚本可以同时运行，总计默认 6 个训练进程。若 MPS 内存不足，先结束 TCN 终端，只保留图模型训练；已有完整结果会被自动复用。

## 三、输出内容

每个模型/种子目录都会保存：

- `best_model.pt`：验证集快降 RMSE 最优的模型；
- `metrics.json`：完整训练与验证指标及防泄露审计；
- `training_history.csv`：逐轮训练/验证指标；
- `validation_predictions.csv`：验证集预测；
- 训练曲线和验证预测图。

全部运行完成后自动生成：

```text
validation_summary/validation_seed_runs.csv
validation_summary/validation_model_summary.csv
validation_summary/summary_audit.json
```

图模型还会生成：

```text
validation_summary/paired_graph_effects.csv
```

其中模型排名只依据验证集，不读取或利用测试集。

## 四、断点续训

脚本再次执行时，会校验 `metrics.json`、`best_model.pt`、模型名称、seed、lookback、预测步长以及测试集读取标志。通过校验的完整 run 会跳过；中断或不完整的 run 会重新训练。
