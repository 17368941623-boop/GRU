# 中文论文初稿说明与证据边界

## 当前主结论

本文当前最稳固的论证链是：60点历史窗口在10个随机种子的完整0715-BACK测试序列上取得最低平均RMSE；固定工艺图与循环历史编码并行融合优于串行“图编码后再做时序”；构造特征整体优于原始变量，但独立贡献最稳定的是目标历史动态。

## 术语约定

| 统一术语 | 首次定义 | 不再使用的写法 |
|---|---|---|
| 模组常规降温过程 | 多冷源、混气、管路传输和末级阀门共同作用的常规降温过程 | 超导加速器降温、测试站降温（作为主叙事） |
| 模组平均温度 Thv | 模组多个温度测点的平均值 | THV、thv混用 |
| 历史窗口 | 截至时刻t的连续历史样本数L | lookback samples（中文正文） |
| 预测步长 | 目标时刻相对当前时刻的离散步数H | 预测未来第N个点位等口语表述 |
| 已知未来控制序列 | u(t)至u(t+H-1)的阀门指令 | 未来测量数据 |
| 固定工艺拓扑 | 根据管路连接和流向预先定义的有向图 | 数据驱动KNN图 |
| 单调KAN边门控 | 只对阀门自身开度使用非减一维样条的边函数 | 全局温度单调KAN |

## 已写入正文的实验事实

- 采样周期10 s，预测步长15，即150 s。
- 训练父数据：0623-BACK、0715-ALL、251130、251226、260118、260403；0617排除。
- 验证：Original 260501；最终测试：Original 0715-BACK完整序列。
- 历史窗口比较：12个长度，每个10个随机种子；L=60的完整测试RMSE最低，为1.180±0.039 K。
- 架构比较：8个主模型，每个10个随机种子；TCN探索结果不放入主图和主表。
- 并行GRU--MLP--GNN的RMSE最低；并行GRU--单调KAN--GNN的MAE、P95较低且局部阀门边函数可解释。
- 特征消融：完整20特征相对raw20的RMSE降低18.75%，目标历史动态是当前唯一经多重比较校正后仍有稳定独立贡献的组。

## 尚不能在正文中写死的结论

- 不能声称KAN的预测精度显著优于MLP；当前RMSE反而略高，且置信区间重叠。
- 不能声称模型已达到传感器噪声极限；仍缺传感器标称精度与重复测量噪声估计。
- 不能声称模型已可直接作为完整MPC内部模型；当前只输出t+15单终点，还没有输出t+1至t+H的完整轨迹。
- 不能声称反事实约束提高了预测精度或外推能力；相关实验尚未完成。
- 不能把20个构造特征都称为有效；若干代理量的独立删除没有显著恶化性能。

## 建议优先补充的实验

1. 精简特征组合：目标历史动态、模组阀门动态、模组耦合及其组合，10个配对随机种子。
2. 反事实单调性：主要阀门增加3%和5%，报告违反率、违反幅值、响应增益及原始测试RMSE变化。
3. 代表性预测曲线：完整0715-BACK曲线、复温转折、再次降温局部窗口和残差。
4. 多时距输出：至少同时报告5、10、15步；若面向MPC，再输出1至H步完整轨迹。
5. 计算效率：单样本与批量候选控制序列推理时延。
6. 新独立批次盲测：至少再保留一个从未参与开发的运行批次。
