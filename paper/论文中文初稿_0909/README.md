# 中文论文初稿工程

## 编译

在本目录使用 XeLaTeX 编译：

```text
latexmk -xelatex main.tex
```

工程中的 `cas-dc.cls` 已做最小兼容修改：在 XeLaTeX 下使用 Unicode 数学字体，避免原模板旧版 STIX 字体导致减号、正负号和省略号显示错误；PDFLaTeX 路径保持模板原有字体配置。
