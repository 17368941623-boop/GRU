# 0912 Raw54-GRU 十随机种子基线

本实验用于测量54个有效原始信号在无PCMCI、无GNN、无KAN、无旧20个构造特征时的预测性能。

## 固定口径

- 采样周期：10 s。
- 历史窗口：60步，即过去10 min。
- 输出：一次性输出未来15步，即150 s的 `Thv` 温度轨迹。
- 历史分支：54个原始信号输入GRU。
- 控制分支：沿用0908的8个已知未来可规划控制量，直接输入控制GRU，不做KAN变换。
- 训练：7个父过程的Original、Aug_01和Aug_02；新导出的260617数据完整，因此恢复使用。
- 验证：260428的Original。
- 冻结测试：260721-BACK，本轮代码不读取。
- 因果安全：读取新过滤阶段生成的飞点端点清单；任何包含这些端点的历史/未来窗口均不使用。
- 随机种子：42、52、62、72、82、92、102、112、122、132。

这里的 `Raw54-GRU` 是与0908无图基线同类的双时序分支：一个GRU编码历史状态，一个GRU编码候选未来阀门序列。名称中的Raw54表示历史输入不含人工构造特征。

## 启动与查看

```powershell
.\start_background.ps1
.\check_progress.ps1
```

需要停止时：

```powershell
.\stop_training.ps1
```

单个seed保存权重、逐时刻预测、训练曲线、归一化参数和完整指标。十个seed完成后，`outputs/summary/` 自动生成多seed汇总CSV及300 dpi PNG/PDF图。
