# Thv lookback=15–120 实验归档

本目录归档 `lookback_plateau_15_120_rapid_rmse` 图对应的模型、训练记录、完整测试结果、绘图文件和复现脚本。原始实验目录未移动或删除，这里是为论文整理的独立副本。

## 图中指标的定义

- 任务：根据历史过程变量和未来已知阀门序列预测 `Thv(t+15)`。
- 训练目标：先预测 `Thv(t+15)-Thv(t)`，再加回当前 `Thv(t)` 得到绝对温度预测。
- 测试数据：仅使用未扩增的 `Original 0715-BACK`。
- 图中 RMSE：0715-BACK 完整测试序列上全部合法且统一的预测起点，不是快降离散子集。
- 公平比较：所有 lookback 均使用要求 120 步公共历史条件的同一组 10,659 个预测起点。
- 重复次数：12 个 lookback × 10 个随机种子，共 120 个冻结 GRU 模型。
- 图中圆点：各随机种子的测试 RMSE；折线和误差棒：均值 ± 样本标准差。

原始序列最前面的公共历史区间和最后无法形成 15 步标签的区间不属于合法预测窗口，因此“完整测试”指完整序列上的全部可比较预测窗口。

## 数据划分与防泄露约束

- 训练数据源：`0623-BACK`、`0715-ALL`、`251130`、`251226`、`260118`、`260403`。
- 排除的数据源：`0617-ALL`。
- 验证集：未扩增的 `Original 260501`，用于早停与冻结模型权重。
- 测试集：未扩增的 `Original 0715-BACK`，在训练完成后执行冻结权重推理。
- Standardizer 只使用训练数据拟合。
- 历史温度、压力和流量只使用到当前时刻；未来输入只包含已知阀门序列 `u(t)…u(t+14)`。
- 窗口不跨越源文件边界。

注意：12 个 lookback 都在 0715-BACK 上进行了比较，因此该数据现在属于事后模型比较/评估集，不能再同时宣称为“从未参与任何模型选择的最终独立测试集”。

## 模型配置和主要结果

- 模型：单层 GRU，history hidden=64；future-control hidden=32；fusion hidden=64。
- 每个模型可训练参数：26,657。
- 预测步长：15 个采样点，即 150 s。
- 数值最优：lookback=60，完整测试 RMSE 为 `1.1803 ± 0.0391 K`。
- lookback=65：`1.1853 ± 0.0226 K`。
- Persistence 基线：`1.9780 K`。

## 目录说明

- `model_runs/`：120 个冻结模型。每次运行保留模型权重、训练/验证指标、逐轮训练历史、归一化参数与报告、防泄露审计及训练曲线。
- `test_results/`：120 次完整测试结果、按 lookback 汇总表和测试清单。
- `scripts/`：训练、批量运行和冻结模型完整测试脚本。
- `figure/`：绘图源文件与 PNG、PDF、SVG、TIFF 四种输出格式；`figure/qa/` 保存排版检查记录。
- `archive_manifest.csv`：归档内容（不含清单自身）的相对路径、大小和 SHA-256。

为控制归档体积，没有复制每个模型的大型逐点验证预测 CSV；论文图所需的模型、逐轮指标和完整测试汇总均已保留。

## 复现说明

训练和重新测试需要把同版本的 `processed_data` 放在本目录下，或通过 `--data-dir` 指向原数据目录。脚本的默认模型目录和测试结果目录已经改为本归档内的相对路径。

重新生成图时，在 `figure` 目录执行：

```text
python lookback_plateau_15_120_rapid_rmse.py
```

重新执行冻结模型完整测试时，在 `scripts` 目录执行：

```text
python evaluate_lookbacks_on_full_test.py --data-dir <processed_data路径>
```
