# 服务器导出结果归档：Thv(t+15) GRU lookback

## 结论

- 最佳 lookback：`60` 个采样点。
- 采样周期：10 s，因此历史长度为 600 s（10 min）。
- 选择依据：Original 260501 快速降温子集的三种子平均 RMSE；
  Original 0715-BACK 不参与 lookback 排名。
- 完整性：lookback 10--60（步长5）均包含种子42、62、82，共33个运行；
  汇总状态为 `formal`，缺失运行数为0。

## lookback=60 的三种子结果

- 完整验证 RMSE：`0.193058 ± 0.005408 K`。
- 快速降温验证 RMSE：`0.668990 ± 0.016845 K`。
- 完整验证 MAE：`0.075389 K`。
- 快速降温验证 MAE：`0.188625 K`。
- 快速降温验证 P95绝对误差：`0.304460 K`。
- 快速降温方向准确率：`99.9167%`。
- 相对 Persistence：完整验证 RMSE 降低 `76.5751%`，快速降温RMSE降低
  `79.3168%`。
- 0715-BACK源行0--7300诊断窗口 RMSE：`1.454635 ± 0.053732 K`。
- 该测试窗口快速降温 RMSE：`3.732796 ± 0.157218 K`。

lookback=60 相对 lookback=20 的快速验证 RMSE 平均降低 `0.061058 K`，
三个对应种子均获胜；完整验证 RMSE 平均降低 `0.049383 K`，三个种子也
均获胜。相对最接近的 lookback=50，快速验证RMSE平均降低 `0.016522 K`，
三个种子中两次获胜。因此60是当前结果下合理但优势不算巨大的选择。
