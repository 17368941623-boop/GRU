# LSTM/GRU 基础循环层对比结论

分析日期：2026-08-29。本文件是旧划分（验证260118、测试260501）的历史结构筛选记录；当前正式划分已经交换，结果不得作为新划分下的验证或测试性能。

## 对比条件

LSTM 与 GRU 使用完全相同的训练/验证数据、共同预测起点、历史输入列、未来 `u(t)..u(t+4)` 阀门分支、Delta 目标、快速降温加权 Huber、优化器、hidden size 和早停规则。唯一变化为历史编码器的循环单元。

测试组合为 lookback `20 / 40` 与 seed `42 / 62 / 82`，共 12 次。模型选择阶段没有读取 `260501` 测试集。

## 汇总结果

| 模型 | 快速降温验证 RMSE (K) | 全验证集 RMSE (K) | 参数量 |
|---|---:|---:|---:|
| GRU | 0.16386 ± 0.03031 | 0.06369 ± 0.00854 | 24097 |
| LSTM | 0.18739 ± 0.04500 | 0.07356 ± 0.01446 | 29601 |

GRU 相比 LSTM 的平均快速降温 RMSE 下降约 12.6%，全验证集 RMSE 下降约 13.4%，参数量减少约 18.6%。同 seed、同 lookback 的配对结果中，GRU 在快速降温 RMSE 上赢 4/6，在全验证集 RMSE 上赢 5/6。

快速降温配对差值的样本量只有 6，bootstrap 95% 区间略跨越 0，因此当前证据支持“优先选择 GRU 继续实验”，但不宜在论文中写成 GRU 对快速降温具有统计显著优势。全验证集 RMSE 的配对优势更稳定。

## 历史长度信号

GRU 从 lookback=20 增加到 40 后：

- 快速降温验证 RMSE：0.18417 → 0.14355 K；
- 全验证集 RMSE：0.07025 → 0.05712 K。

3 个 seed 中，快速降温 RMSE 有 2 个明显改善、1 个基本持平；全验证集 RMSE 3 个均改善。因此较长历史对 GRU 有实际价值。由于 40 是原实验上界，下一轮应扩展到 60，并让所有 lookback 使用共同 60 步历史的同一批预测起点。

## 最佳单次结果与误差形态

当前最佳单次为 GRU、lookback=40、seed=62：

- 全验证集 RMSE：0.05245 K；
- 快速降温 RMSE：0.12117 K；
- 快速降温 MAE：0.04557 K；
- 快速降温 P95 绝对误差：0.09646 K；
- 快速降温最大绝对误差：2.78134 K；
- 快速降温方向准确率：1.0。

P95 很低而最大误差较大，说明 RMSE 被少数极端快速跃迁点明显拉高。后续 lookback 排名仍以快速降温 RMSE 为主，但论文中应同时报告 MAE、P95、最大误差及对应曲线，避免均值指标掩盖极端事件。

## 训练耗时说明

本次 Apple MPS 结果中，GRU 平均每轮约 24.97 s，LSTM 约 15.32 s。GRU 虽参数更少却更慢，较可能来自当前 PyTorch/MPS 对不同循环算子的实现效率，不应表述为 GRU 在一般硬件上必然更慢。模型选择仍优先依据预测性能；部署效率需要在最终硬件上另行基准测试。

## 当前决策

冻结基础循环层为 GRU，正式扫描 lookback `10 / 15 / ... / 60`，每个窗口使用 seed `42 / 62 / 82`。特征消融和 KAN/固定拓扑图分支应在最佳 lookback 冻结后开始，避免同时改变历史长度与模型结构。
