# Thv 低误差与数据泄露审计

审计日期：2026-08-29。文中的0.05245 K和1722个快速窗口用于解释交换划分前的历史结果；当前正式代码已改为验证=260501、测试=260118，必须重新训练。

## 结论

现有代码没有发现 Future Thv、未来温度、未来压力或未来流量进入历史输入，也没有发现训练/验证源文件重叠。模型训练目标是：

```text
Delta_Thv_5(t) = Thv(t+5) - Thv(t)
predicted_Thv(t+5) = Thv(t) + predicted_Delta_Thv_5(t)
```

因此最终预测量确实是50秒后的Thv。由于恢复后的Thv误差等于Delta预测误差，两者RMSE在数学上完全相同。

## 标签对齐外部核验

使用当前最佳单次结果 `GRU / lookback=40 / seed=62` 的 `validation_predictions.csv`，再直接读取过滤后的 Original 260118 CSV：

- 检查预测窗口：16214个；
- `current_Thv_k == filtered_raw_Thv[source_row_index]`，最大绝对偏差为0；
- `actual_Future_Thv_5step_k == filtered_raw_Thv[source_row_index+5]`，最大绝对偏差为0；
- `actual_delta == future_Thv-current_Thv`，最大数值偏差约 `3.55e-15 K`；
- `predicted_Thv-current_Thv == predicted_delta`，最大数值偏差约 `8.44e-14 K`。

训练代码现已增加运行时逐文件标签对齐断言。只要 `Future_Thv_5step` 不等于同一连续源曲线的 `Thv(t+5)`，程序会在训练前停止。

## 当前输入时间范围

历史GRU输入只覆盖 `t-lookback+1 ... t`。显式输入列为20个当前/历史原始量，不含任何 `Future_*` 列。

未来分支使用8个阀门的：

```text
u(t), u(t+1), u(t+2), u(t+3), u(t+4)
```

不使用 `u(t+5)`，也不使用未来温度、压力或流量。该做法对“给定未来控制轨迹的条件预测/MPC模型”是合法的，但不能写成完全不知道未来控制量的普通自由预测。离线记录中的 `u(t+1)..u(t+4)` 可能包含反馈控制器根据中间状态作出的动作，因此相较于只用时刻t信息的模型，它会明显降低误差。

## 数据划分

- 训练：`0623-BACK / 0715-ALL / 0715-BACK / 251130 / 251226 / 260403`；训练脚本在拟合任何统计量之前去除 `0617-ALL`。
- 验证和lookback选择：Original `260501`，不含扩增副本。
- 测试：Original `260118`。
- 当前lookback训练代码先只加载训练/验证数据完成训练、早停和checkpoint选择，随后才加载 `test_full_clean.pkl` 计算固定源行窗口6500--11500的测试指标。

`test_clean.pkl` 是根据阀门事件密度选出的动态段，不用于本次固定窗口指标。测试窗口直接从完整 Original 260118 的 `test_full_clean.pkl` 提取；训练集快速阈值不会根据260118重新拟合。

## 为什么全区间RMSE很低

当前最佳单次验证结果中：

- `corr(Thv(t), Thv(t+5)) = 0.999988`；
- 67.15%的窗口在50秒内温度变化绝对值不超过0.1 K；
- 89.64%的窗口不超过0.2 K；
- Persistence全区间RMSE为0.41741 K；
- 模型全区间RMSE为0.05245 K。

因此全曲线中大量平稳/缓慢变化样本会令总体RMSE很低。它不是最能体现模型价值的指标。

快速降温子集由训练集Delta的10%分位数阈值定义。交换划分前的260118历史验证结果包含1722个快速窗口：

- Persistence快速RMSE：1.25789 K；
- 模型快速RMSE：0.12117 K；
- 快速MAE：0.04557 K；
- 快速P95绝对误差：0.09646 K；
- 快速最大误差：2.78134 K。

快速RMSE去掉唯一最大误差点后约为0.10097 K，说明结果不完全由一个点决定，但极端跃迁仍显著影响RMSE。

## 不是泄露、但会让结果偏乐观的因素

1. 当前Thv作为输入并预测短期Delta，这是合理的残差预测，但任务本身比从零预测绝对温度容易。
2. 模型使用已知未来5步阀门，因此属于条件预测。
3. 当前正式代码使用260501进行早停、随机种子和lookback选择；最佳验证RMSE仍存在模型选择偏乐观，因此额外报告260118固定窗口指标。
4. 温度飞点和穿过修复点的输入/标签路径已被排除，验证数据比未清洗原始曲线更干净；过滤程序没有进行温度平滑或阀门平滑。
5. 训练扩增副本只在训练源内部，增加了相似样本数量，但验证/测试源与训练源按parent完全分离，因此不是跨集合泄露。
